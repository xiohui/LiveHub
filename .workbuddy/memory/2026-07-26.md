## 运动页 BUG 修复 + 本周打卡色条（设计任务 · 后续）
用户反馈 3 项：
1. **BUG 运动时长小数点超长**：`总时长` 统计里 `mins = totalMinutes % 60`，有氧时长存成小数后 `totalMinutes` 成浮点 → 长小数。修复：`renderStats` 的 totalMinutes 用 `Math.round(...)`；有氧/核心的时长、距离在展示与保存时均取整（距离保留 1 位小数 `fmt1`/`round1`）。form 的用时(分钟)/时长(秒) input 改 `step="1"`，保存时 `Math.round`；距离 `step="0.1"` 保存时 `*10/10` 取 1 位。
2. **BUG 本周打卡框整个不见**：`render()` 未被路由器 await，快速切 Tab 再切回时 `destroy()` 把 `$el` 置空，异步 `renderHeatmap` 等继续跑 `container.innerHTML` → 抛错 → 路由 catch 换错误页，或热力图 `<div>` 永远空(`.glass` 无内容无内边距→视觉消失)。修复：在 `renderTodayCard/renderHeatmap/renderStats/renderTodayList` 的 `await` 之后加 `if (!$el) return;` 守卫；`.heatmap-day` 加 `min-height:32px` 兜底，避免 aspect-ratio 折叠。
3. **本周打卡按类别显示色条**：废弃原 l1-l4 青蓝强度，改每个格子内按当天打卡类别叠色条。类别配色：有氧 `#22d3ee`(青蓝) / 力量 `#fb7185`(珊瑚) / 核心 `#a78bfa`(紫)；每格最多 5 条(`slice(0,5)`)，条数=当日打卡次数，颜色=类别；新增 `.heatmap-legend` 三色图例（有氧/力量/核心）。
