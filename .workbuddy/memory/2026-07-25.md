# 2026-07-25

## LiveHub 项目优化（移动端 PWA：生活/运动/学习管理，IndexedDB 存储）

### 修复的 Bug
1. **严重数据丢失**：`store.js` 的 `seedMaterials` 每次进入"学习"页都会 `delete` 全部 materials 再重建，导致用户收藏资料被清空。改为仅在使用手册（`isManual`）不存在时补充，不再删除用户数据。
2. **日期时区**：`life.js` 待办/Vlog 默认日期用 `new Date().toISOString()`（UTC），中国时区会差一天，影响"今日待办"统计。改为复用 `store.js` 的本地 `todayStr()`（已 export）。
3. **跨页跳转时序**：首页"写 Vlog"用 `setTimeout(100ms)` + `Store.emit('switch-life-tab')` 切标签，时序不稳。改为 `Store.setLifeTab/consumeLifeTab` 状态传递，在 life.js render 顶部消费。

### 性能 / 健壮性
4. `db.js`：`openDB()` 改为缓存 `dbPromise`，避免每次读写新建 IndexedDB 连接。
5. `sport.js`：运动项目名称/emoji 拼入 `data-*` 属性未转义，含引号会破坏结构。统一用 `escHtml` 处理。

### 新能力
6. 新增 `sw.js`（stale-while-revalidate 缓存应用外壳）+ `app.js` 注册 Service Worker，使应用可离线、可安装为 PWA。

### 无障碍 / 元信息
7. `css/style.css` 增加 `@media (prefers-reduced-motion: reduce)` 降级动画。
8. `index.html` 补充 `description`、`<meta name="mobile-web-app-capable">`、`<link rel="apple-touch-icon">`。

### 验证
- `node --check` 全部 JS 通过。
- `python -m http.server` 起服，index/manifest/css/全部 js/sw/icon 均 HTTP 200。
- 已 grep 确认无遗留 `switch-life-tab` / `toISOString().slice` / `lh_manual_ver` 引用。

## 第二轮优化（用户反馈 + 继续优化）
1. **底部导航在 Pura 小屏看不见**：根因是 `#phone` 用 `min-height:100vh; height:100dvh`，设备浏览器不支持/不稳定 dvh 时回退 100vh（含浏览器底栏区域），`overflow:hidden` 把导航裁掉。改 `#phone { position: fixed; inset: 0 }` 精确贴合可视区。同时把 `.nav-item` 未选中颜色从 `--text-muted`(#64748b，暗底几乎不可见) 调亮为 `--text-secondary`(#94a3b8)。
2. **XSS 加固**：首页时间线 `r.text` 由用户输入（待办标题/书名/运动名）构成，原未转义 → home.js 增加 escHtml 并包裹；sport.js 运动名渲染（今日卡片 + 今日列表）补 escHtml。
3. **去重**：sport.js 移除重复的本地 `todayStr()`，改 `import { todayStr } from '../store.js'`。
4. **最近动态排序 bug**：`getDashboardData` 原用 `time`(HH:MM 字符串) localeCompare 排序，跨天错序 → 改为按 `ts`(createdAt 时间戳) 数值排序。

### 验证（第二轮）
- `node --check` 全部 JS 通过；HTTP 起服 index/css 200；served css 已含 `position: fixed; inset:0`。
- grep 确认 sport.js 无重复 todayStr、CSS 无 100vh/100dvh、导航颜色已改（仅占位符保留 text-muted）。
